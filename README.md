# Lantern Moth

A chill scrolling screen arcade game. Fly as a moth through the night-sky, collecting lanterns to stay alive. Dodge enemies and advance into the night for as long as you can!

**Play:** https://krialtestynedaxt.github.io/lantern-moth/

## Controls
- **Mouse/Touch:** Drag anywhere to steer.
- **Keyboard:** P or ESC to pause. F toggles fullscreen.

## Testing
- Open the play link in any browser and save your score for the online leaderboard!
- Found a bug or have an idea? Open an **Issue** on this repository and include a screenshot. If a red error bar appears in the game, screenshot that too.

## Online leaderboard
- Scores are saved on a server, with each player (one device) showing the best run per board.
- The server refuses offensive names, impossible scores and rapid-fire submissions.

## Versions
- `index.html` is always the latest game.
- Each update raises the version by 0.01 and gets an entry in [CHANGELOG.md](CHANGELOG.md).
- Each version is its own commit titled "Lantern Moth v2.xx".
- Every new version automatically gets a tag (`v2.xx`) and a **Release** with its changelog notes and a downloadable `LanternMoth-v2.xx.html`. See the Releases list on the repository page.
